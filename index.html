03 / SIDE B — 歌词 LRC / YRC / FOCUS BAND

歌词，
不是字幕。

该亮的那一句留在焦点里。其他字退到后面，不抢拍、不迷路。 手动翻过歌词，它会自己回到音乐身边。

  1. 01

    逐字弹簧

    LRC / YRC 解析，逐字强调，让字跟着声音的弹性走。

  2. 02

    35% 焦点带

    渐进遮罩与距离模糊，只把正在唱的那一行拉近。

  3. 03

    随手带走

    字号与字重实时预览，多选复制，或把歌词导出成 PNG。

04 / INTERFACE ONE PAGE TREE · ONE STATE

一套页面，
换一种姿势。

桌面、手机、车机与大屏共享同一套页面与状态。 不是四份互相追赶的界面，而是同一张唱片，换一个摆放方式。

01

桌面

侧边栏、完整播放条、可调的 80–175% DPI。窗口多大，布局都保持清醒。

SIDEBAR / TRANSPORT
02

手机

底部标签栏与迷你播放器，沉浸式正在播放页。单手也能够到每个动作。

TAB BAR / MINI PLAYER
03

车机

进入即放大到 135%，触控目标更宽。路况之外，只留下必要的操作。

135% SCALE / TOUCH
04

大屏

电视与投影自动进入大屏模式。方向键按位置移动，焦点永远看得见。
